🐚 Shell / Bash
#!/usr/bin/env bash
set -euo pipefail

APP="myapp"
ENVIRONMENT="${1:-dev}"

echo "[INFO] Deploiement de ${APP} sur ${ENVIRONMENT}"
docker compose -f "docker-compose.${ENVIRONMENT}.yml" up -d --remove-orphans
curl -fsS "http://localhost:8080/health" || { echo "[ERROR] healthcheck KO"; exit 1; }

🧱 Jenkinsfile (Declarative Pipeline)
pipeline {
    agent { label 'linux' }
    options { timestamps(); timeout(time: 30, unit: 'MINUTES') }
    environment { APP_ENV = 'dev' }

    stages {
        stage('Build') {
            steps { sh './gradlew clean build' }
        }
        stage('Test') {
            steps { sh './gradlew test' }
            post { always { junit 'build/test-results/**/*.xml' } }
        }
        stage('Deploy') {
            when { branch 'main' }
            steps {
                withCredentials([string(credentialsId: 'deploy-token', variable: 'TOKEN')]) {
                    sh './deploy.sh "$APP_ENV"'
                }
            }
        }
    }
    post {
        failure { echo 'Pipeline en echec' }
    }
}
🅰️ Ansible (playbook YAML)
---
- name: Deploy nginx
  hosts: web
  become: true
  vars:
    nginx_port: 8080
  tasks:
    - name: Install nginx
      ansible.builtin.package:
        name: nginx
        state: present

    - name: Deploy config
      ansible.builtin.template:
        src: nginx.conf.j2
        dest: /etc/nginx/nginx.conf
        mode: "0644"
      notify: Restart nginx

  handlers:
    - name: Restart nginx
      ansible.builtin.service:
        name: nginx
        state: restarted

4. FAQ

Q Comment relancer un job Jenkins en échec ?
R Ouvrir le job, cliquer sur Rebuild ou Replay, puis vérifier les paramètres avant de lancer.
Q Où sont stockés les secrets ?
R Dans Vault (chemin secret/data/myapp). Ne jamais les committer dans Git.
Q Le déploiement échoue avec « permission denied », que faire ?
R Vérifier les droits du compte de service, puis consulter la page « Dépannage ». Si le problème persiste, contacter @equipe-plateforme.

4.c FAQ accordéon exclusif (un seul panneau ouvert à la fois) + icônes de catégorie

  CI/CD - Pourquoi mon pipeline reste en « pending » ?
Aucun agent disponible avec le label demandé. Vérifier la file d'attente et le label agent { label 'linux' }.
  OPS - Comment tester un playbook sans rien modifier ?
Lancer ansible-playbook site.yml --check --diff (mode dry-run).
  OPS - Comment voir les logs d'un pod ?
kubectl logs -f <pod> -n <namespace>
  SÉCURITÉ - Comment lire un secret depuis Vault ?
vault kv get secret/myapp (token requis).

DANGER : action irréversible, jamais en production sans validation.
