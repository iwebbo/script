4.11 Glossaire (terme / définition)

TermeDéfinition
CIIntégration continue : build et tests automatiques à chaque commit.
CDLivraison / déploiement continu vers les environnements.
IaCInfrastructure as Code : infra décrite et versionnée (Terraform, Ansible).
RollbackRetour à la version précédente après un incident.

4.12 Arbre de décision (si… alors…)

🔀 Si…➡️ Alors…
Le build est rouge et le test échoueCorriger le test, pousser un commit.
Le build est rouge et l'agent est hors ligneContacter l'équipe plateforme (P2).
La prod est indisponibleP1 Lancer le rollback puis ouvrir l'incident.
